## Installation

<InstallTabs name="button" />

Installs the theme tokens too if they are missing. Run `npx shadcn@latest add @ziui/theme`
first to apply the full ziUI palette — see [Installation](/docs/installation).

## Usage

```tsx title="app/page.tsx"
import { Button } from "@/components/ui/button";

export function Example() {
  return <Button>Save changes</Button>;
}
```

## Examples

### Variants

<ComponentPreview name="button-variants" size="sm" />

| Variant | Use for |
| --- | --- |
| `default` | The primary action on a screen. Blue gradient, white label. |
| `secondary` | Most other actions. Surface fill with a 1px ring. |
| `outline` | Actions on tinted or busy backgrounds. Transparent fill. |
| `ghost` | Low-emphasis actions in toolbars and menus. |
| `destructive` | Irreversible actions such as delete. Red gradient. |
| `destructive-secondary` | Less prominent destructive actions. Red label on a surface. |
| `link` | Inline navigation styled as text. |

### Sizes

<ComponentPreview name="button-sizes" size="sm" />

| Size | Height | Notes |
| --- | --- | --- |
| `xs` | 20px | Dense tables and tags. |
| `sm` | 26px | Compact toolbars. |
| `default` | 36px | Standard forms and dialogs. |
| `lg` | 40px | Hero and page-level calls to action. |
| `icon-xs` · `icon-sm` · `icon` · `icon-lg` | 20 · 26 · 36 · 40px | Icon-only, always circular. |

Icon-only buttons have no visible text — always pass `aria-label`.

### Loading

<ComponentPreview name="button-loading" size="sm" />

`loading` disables the button, sets `aria-busy` and shows a spinner before the label.
With `asChild`, no spinner is injected (Slot needs exactly one child); only
`aria-busy` and `data-loading` are set, so style the loading state yourself.

### As a link

```tsx
<Button asChild variant="secondary">
  <a href="/pricing">See pricing</a>
</Button>
```

## API reference

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "secondary" \| "outline" \| "ghost" \| "destructive" \| "destructive-secondary" \| "link"` | `"default"` |
| `size` | `"xs" \| "sm" \| "default" \| "lg" \| "icon-xs" \| "icon-sm" \| "icon" \| "icon-lg"` | `"default"` |
| `loading` | `boolean` | `false` |
| `asChild` | `boolean` | `false` |

All native `<button>` props are forwarded.
