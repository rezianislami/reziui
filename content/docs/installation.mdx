---
title: Installation
description: Add the ziUI registry to your project.
---

ziUI targets **Tailwind CSS v4**. Projects on Tailwind v3 are not supported.

1. Set up shadcn in your project: `npx shadcn@latest init`
2. Add the ziUI namespace to `components.json`:

```json
{
  "registries": {
    "@ziui": "https://<domain>/r/{name}.json"
  }
}
```

3. Install the ziUI theme: `npx shadcn@latest add @ziui/theme`
4. Install a component: `npx shadcn@latest add @ziui/button`

Install the theme directly (step 3) before any component. Components list
`@ziui/theme` as a dependency, but when it arrives that way the shadcn CLI only
adds missing variables and keeps your existing `--background`, `--primary`,
`--border` and friends. Components still render correctly without it — they
read their own `--btn-*` tokens — but surfaces and borders follow your current
theme instead of ziUI's.

Dark mode follows the shadcn convention: add the `dark` class to an ancestor
(for example `<html class="dark">`, or let `next-themes` do it).

The `--font-sans` token is expected to point at [Geist](https://vercel.com/font).
With `next/font`, register Geist under that variable:

```tsx
const geistSans = Geist({ variable: "--font-sans", subsets: ["latin"] });
```
